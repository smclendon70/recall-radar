Make a Pro unlock code

For the app owner only. Type a secret code (for example RADAR-GOLD-7731). This tool turns it into a "fingerprint" you paste into the app's CONFIG. The real code is never stored in the app, so people can't find it by peeking at the code.

Then in index.html, find proCodeHashes: [] and put the fingerprint inside quotes, like:
proCodeHashes: ["paste-it-here"]

Put the secret code on your payment provider's "thank you" page or receipt so buyers can unlock Pro.
